### Fixed

- Appliance installer first-install polish. The role screen no longer pre-selects "Additional node" (a first-time operator pressing Enter was asked for a control-plane URL they did not have) and says "First install? Choose First node". A clock found behind the image's build date can now be set from the installer, and the NTP servers typed on Time source can be test-queried once. Timezone is picked from a region and city menu, and a typed name is matched case-insensitively. The disk list shows the tail of each disk's serial number and tags `[too small]` disks before they are picked, and Back on the keep-/var menu returns to the disk list. The Done screen explains how to log in (console dashboard, SSH, the self-signed certificate warning) and offers Reboot, Power off or a shell. A headless preseed with no `timezone:` (or, on an Additional node, no `k3s:`) is now fully unattended instead of waiting at Welcome, and `--check-preseed` names whatever still keeps a run from being unattended. Stale or VM-only wording was corrected, the Welcome list now matches the questions asked, and `docs/deployment/APPLIANCE.md` has a screen-by-screen walk-through. (#4551)
