### Fixed

- API-token write scopes now cover the plainly-domain routes that sat outside their path prefixes (#3302): `ipam:write` admits address sets, multicast, AV flows and reserved ranges, custom-field definitions and `POST /nmap/scans/{id}/stamp-discovered`; `dns:write` admits domains and ACME account register / revoke; `dhcp:write` admits `POST /new-devices/block`. Request submit / approve / reject / cancel, change-request decisions and Copilot proposal apply now admit a token holding any write scope, then refuse with a 403 naming the missing scope unless it is the one the operation's own family needs. Cutover, Trash restore / purge and other cross-domain routes still need an unrestricted token.
