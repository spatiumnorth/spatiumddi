### Fixed

- An RFC 2136 dynamic update (Windows DNS without credentials, BIND9) that the server answered REFUSED, NOTAUTH or any other non-NOERROR code was counted as applied: the API returned no provider warning and the sync reported it pushed on every pass. The reply is now checked and the failure surfaces like any other provider error ([#4939](https://github.com/spatiumnorth/spatiumddi/issues/4939)).
