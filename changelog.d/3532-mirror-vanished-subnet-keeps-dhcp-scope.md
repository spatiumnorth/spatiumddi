### Fixed

- When a network an integration mirrors goes away (a Docker network removed, a Kubernetes CIDR, a Proxmox, UniFi, OPNsense, cloud or firewall subnet), the next sync no longer deletes its subnet together with a DHCP scope an operator built on it, live or in the Trash, with its pools and reservations. A subnet that still carries anything of the operator's (a DHCP scope, addresses, tags, custom fields, a domain link, a registry entry, or an edit) is released to the operator instead, the same test a deleted integration target already used, and every subnet a sync releases or deletes now has its own audit row saying the source network is gone (#3532).
