### Fixed

- The appliance's GRUB recovery boot entry and emergency mode gave no shell on a default install, because they asked for the root password and root is locked (emergency mode gave a password-free root shell, but only on the slot the installer wrote). Both now ask for a username and password on both the screen and the serial console, on every slot, accept the admin account (any member of the `sudo` group; `sudo -i` works) or root when root has a password, and continue the boot when you leave the shell. In emergency mode the login mounts `/var` and `/etc` read-only for the session; when `/var` cannot be mounted it says so and gives no shell without a password. (#5027)
