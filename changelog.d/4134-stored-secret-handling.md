### Fixed

- Editing the URL, address or host of a calendar, SNMP device, integration, webhook, forwarding target, AI provider, auth provider, agentless DNS/DHCP server or backup destination that keeps a stored credential now asks for that credential again (422 naming the changed field) instead of sending the stored one to the new place; APT source URIs and proxy URLs that embed `user:pass@` are shown masked in Settings, the support bundle and the Copilot tool, and saving the masked form keeps the stored credential as long as the scheme, host and port are unchanged (a different host asks for the `user:password` again).
