### Added

- One-shot phpIPAM importer. `POST /api/v1/ipam/import/phpipam/{test-connection,preview,commit}` reads a live phpIPAM instance through its REST API (app code, or user and password; TLS verified unless you opt out) and builds native rows: sections to spaces (a section whose subnets sit in several VRFs is split per VRF), VRFs, nested subnets to blocks and subnets, addresses with hostname, MAC, owner and state, VLANs, and custom fields as typed definitions. The preview writes nothing and lists conflicts and everything that will not map; commit is idempotent, defaults every conflict to skip, audits each row, stamps `import_source=phpipam`, and never writes into the Trash. Credentials are used for the one request and never stored. Behind the new default-on `ipam.import.phpipam` module, with Copilot preview and propose tools. (#4734)
