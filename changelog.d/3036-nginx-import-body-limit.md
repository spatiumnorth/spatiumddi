### Fixed

- **Imports over 1 MiB no longer fail with an nginx 413 through the bundled web port (#3036).** The frontend nginx (Compose image and appliance) kept its 1 MiB default for the import routes, so a BIND9 archive, Kea / ISC file or IPAM CSV over 1 MiB, or a commit carrying a large preview, was refused with an HTML page before the api saw it, though the importers accept 50 MiB (DNS) and 25 MiB (DHCP, IPAM). The importers, the DNS zone spreadsheet import, the supervisor's pcap upload and the DNS agent's ingested-records push now have their own nginx location that streams the body to the api (up to 128 MiB), so each route's own limit applies and an over-limit body gets the api's JSON 413. Other `/api/` routes keep the 1 MiB limit. The raw Kubernetes Ingress sets `proxy-body-size: 4g` with request buffering off, and the chart's Ingress values suggest the same.
