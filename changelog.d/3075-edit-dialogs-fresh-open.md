### Fixed

- Edit dialogs no longer show a stale value or write it back. Edit IP Space, Edit Static Assignment, Edit Record and Edit DHCP Scope now read the object fresh when they open, so a change made elsewhere since the list was loaded (the space panel after a Save, an inline hostname edit in the IP table, a Save a moment ago) shows up. Edit IP Space, Edit Static Assignment and Edit Record send only the fields you changed, and a Save that changes nothing sends nothing. A static assignment update that repeats the stored values no longer rewrites its IPAM address or DNS. The space panel header follows the refetched space, and inline IP edits refresh the static assignments list. (#3075, #3076, #3077)
