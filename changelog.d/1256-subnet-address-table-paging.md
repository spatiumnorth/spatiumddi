### Fixed

- The IPAM subnet address table no longer loads every row of a subnet: it fetches one page at a time (100 to 1,000 rows, with Previous / Next and a page-size control) and the server applies the column filters (including begins / ends / regex modes), the free-text tag filter, the tag chips and the column sort across all pages. Pool-boundary and free-range rows are drawn per page, and "Select all N matching" asks the server for every matching id, so bulk edit and delete reach rows beyond the visible page. `GET /subnets/{id}/addresses` gains `address`, `description`, `tag_text` and `match` filters; a subnet that fits one page looks as before. The DNS-state filter and DNS column sort only narrow or order the rows on the page, and the MAC filter no longer matches the OUI vendor name.
