### Added

- Copilot Watch (phase 1): an opt-in `ai.watch` module (off by default, needs the Copilot module) that runs the Copilot unattended as a read-only service user on a schedule, on Run now, and when an alert opens or gets worse. It reads alerts, conformity, DNS / DHCP server health and recent audit rows, and records evidence-backed findings that close by themselves when the evidence clears. Findings are triaged (acknowledge, dismiss with an optional mute, reopen) from Copilot Watch in the admin menu, with a Security dashboard card and four read-only MCP tools. Daily token and cost budgets, a runs-per-hour limit and an automatic pause after repeated failures bound the cost; hosted providers are refused unless allowed, and an `openai_compat` provider can now be marked on-prem.
