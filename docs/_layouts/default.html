{%- comment -%} Docs page layout — single column, top nav, no sidebar. Every page on the site uses it, including the index (#1070 removed the product landing page). `root` is a relative prefix ("", "../", "../../") computed from the page's own depth, used for every asset and nav link. Why not site.baseurl: this tree is served from two Pages sites at different mount points (the org site at "/" and the project site at "/spatiumddi/"). GitHub Pages does inject the right baseurl per build, so baseurl would work in production — but it is empty for a local `jekyll build`, which would then emit root-absolute links that only resolve if you happen to serve the output at "/". Relative prefixes are correct at any mount point, production or local, which is what makes the site previewable before it is published. {%- endcomment -%} {%- comment -%} Depth = number of '/' separators after the leading one. The 'x' sentinel is load-bearing: Liquid's split drops trailing empty strings, so a directory URL like "/deployment/" would otherwise measure the same as a top-level page and pull assets from the wrong prefix. Appending a character gives the trailing segment something to be, making "features/DNS.html" and "deployment/" both measure depth 1. {%- endcomment -%} {%- assign _path = page.url | remove_first: '/' | append: 'x' -%} {%- assign _depth = _path | split: '/' | size | minus: 1 -%} {%- capture root -%} {%- if _depth > 0 -%}{%- for i in (1.._depth) -%}../{%- endfor -%}{%- endif -%} {%- endcapture -%} {% include head.html root=root %} {% include nav.html root=root %} {%- comment -%} Version banner (#1164). These docs track `main`, so a reader running a release may be reading behaviour that has not shipped. The links are absolute (config `links`), so the banner is correct on both Pages sites and in a local build. `site.data.build` is written ONLY by docs-publish.yml, into the published copy (never committed): it carries the commit, date and latest release. Without it (project Pages site, local `jekyll build`) the banner is the generic form. {%- endcomment -%}
